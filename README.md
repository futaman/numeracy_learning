# すうじ探偵事務所

数字の「見せ方」にだまされない力を、探偵ゲームで鍛えるアプリです。
対象は小学校高学年〜中学生。文系の大人にもわかるように作っています。

数見町（かずみちょう）では、ゴマカシ社がグラフや数字の見せ方で町の人をだましています。
数字そのものはウソではありません。見せ方のトリックを、相棒の宇宙人留学生ポチョ、ルーペ所長と一緒に見破ります。

## いま遊べるもの

試作として、事件 1-1「パン屋の売り上げ急上昇！」だけ遊べます。
縦軸が0から始まっていないグラフのトリックを、3Dのビルで体験します。

1. 依頼：チラシのグラフでは、4月が1月の6倍に見える
2. 予想：何倍になったと思う？
3. 調べる：カメラを引くと、地面の下に埋まっていたビルが見える
4. 見破る：トリックを選ぶ
5. 直す：地面の高さを0まで下げる
6. 解説と合言葉カード

## 動かし方

ES modules を使うので、ファイルを直接開くのではなくローカルサーバーで開きます。

```bash
python -m http.server 8123
```

ブラウザで http://localhost:8123/ を開きます。
WebGL が使えない環境では自動で2D版になります。URLの末尾に `?2d` をつけると2D版を確認できます。

## テスト

```bash
npm test
```

Node.js 18 以上が必要です。依存パッケージはありません。

## 構成

| パス | 中身 |
| --- | --- |

| `src/main.js` | 事件の流れ（会話・操作・保存） |
| `src/cases/` | 事件のデータ |
| `src/judge.js` | 判定ロジック（テスト対象） |
| `src/scenes/buildings3d.js` | 3Dの場面（Three.js、トゥーン表現） |

| `src/characters.js` | キャラクターの絵 |
| `src/text.js` | ふりがな記法 `{漢字\|かんじ}` の変換 |
| `vendor/three.module.js` | Three.js r170（MIT License） |
| `test/` | node:test のテスト |
