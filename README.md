# すうじ探偵事務所

数字の「見せ方」にだまされない力を、探偵ゲームで鍛えるアプリです。
対象は小学校高学年〜中学生。文系の大人にもわかるように作っています。

数見町（かずみちょう）では、ゴマカシ社がグラフや数字の見せ方で町の人をだましています。
数字そのものはウソではありません。見せ方のトリックを、相棒の宇宙人留学生ポチョ、ルーペ所長と一緒に見破ります。

## いま遊べるもの

第1章「グラフのワナ」（商店街）と第2章「平均・中央値・差と比」（学校）の10件が遊べます。前の事件を解くと、次の事件が開きます。

| # | 事件 | トリック | 調べ方 |
| --- | --- | --- | --- |
| 1-1 | パン屋「売り上げ急上昇！」 | 縦軸が0から始まらない | カメラを引くと、ビルが地面に埋まっている |
| 1-2 | 八百屋「となりの2倍売れた！」 | 箱の絵を縦・横・奥行きぜんぶ2倍にした（8倍に見える） | 絵を回すと、奥行きも2倍 |
| 1-3 | 携帯ショップ「このシェアを見よ！」 | 立体の円グラフをななめから見せる | カメラを上へ動かし、真上から見る |
| 1-4 | 薬局「菌はゆっくりしか増えない」 | 対数軸（目盛り1つで10倍） | ふつうの目盛りに切りかえる |
| 1-5 | 対決：ノビール「アイスで点が上がる」 | 縦軸が2本で、右の目盛りだけせまい | 右の軸のつまみで目盛りを広げる |
| 2-1 | おこづかい「平均で月5000円！」 | 1人だけとても多い子が平均を引き上げている | シーソーのカメラを引くと、はるか右に1人だけいる |
| 2-2 | ゲームで「リスクが2倍！」 | 1万人に1人が2人になっただけ | カメラを引くと、1万人ずつの人があふれる |
| 2-3 | 給食「どっちも100円の値上げ」 | 差は同じでも、比は2倍と1.02倍 | 「差」と「比」の並べ方を切りかえる |
| 2-4 | テスト「65点は、すごい？」 | 100点との差だけ見せて、みんなの中の位置をかくす | ゴルトンボードで100人の点の山を作る |
| 2-5 | 対決：ヘイキン男爵「分校が町で一番」 | 人数が少ない学校の平均は大きくぶれる | テストを20回やり直す |

どの事件も「依頼 → 予想 → 調べる → 見破る →（直す）→ 解説 → 合言葉カード」の順に進みます。

## 動かし方

ES modules を使うので、ファイルを直接開くのではなくローカルサーバーで開きます。

```bash
python -m http.server 8123
```

ブラウザで http://localhost:8123/ を開きます。
WebGL が使えない環境では自動で2D版になります。URLの末尾に `?2d` をつけると2D版を、`?all` をつけるとカギのかかった事件も選べます（確認用）。

## テスト

```bash
npm test
```

Node.js 18 以上が必要です。依存パッケージはありません。

## 構成

| パス | 中身 |
| --- | --- |
| `index.html` | 画面 |
| `src/main.js` | 事件の流れ（会話・操作・保存・事件の一覧） |
| `src/cases/` | 事件のデータ（1事件1ファイル、`index.js` が遊ぶ順） |
| `src/judge.js` | 判定と、事件の数字の計算（テスト対象） |
| `src/scenes/` | 場面（`*3d.js` は Three.js、`*2d.js` は SVG。`index.js` が事件の `scene` から選ぶ） |
| `src/figures.js` | 解説の1枚の絵 |
| `src/characters.js` | キャラクターの絵 |
| `src/text.js` | ふりがな記法 `{漢字\|かんじ}` の変換 |
| `vendor/three.module.js` | Three.js r170（MIT License） |
| `test/` | node:test のテスト |
